# Rajiya Risha — Official Website

Official website for **Rajiya Risha**, Islamic music artist (nasheed · hamd · naat) — rajiyarisha.com

A single, self-contained `index.html` (no build step). Bilingual: English / বাংলা.

## Edit content
Open `index.html` and look for `EDIT YOUR CONTENT HERE` in the `<script>` near the bottom:
- `VIDEOS` — YouTube video IDs (titles & thumbnails load automatically from YouTube)
- `EVENTS` — upcoming events

## Deploy
Works as-is on GitHub Pages, Vercel or Netlify — just serve `index.html`.
